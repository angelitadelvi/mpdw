Single Moving Average (SMA)

Ide dasar dari Single Moving Average (SMA) adalah data suatu periode dipengaruhi oleh data periode sebelumnya. Metode pemulusan ini cocok digunakan untuk pola data stasioner atau konstan. Prinsip dasar metode pemulusan ini adalah data pemulusan pada periode ke-t merupakan rata rata dari m buah data pada periode ke-t hingga periode ke (t-m+1).

\[S_t = \frac{1}{m} \sum_{i=t-m+1}^{t} X_i\]

# Pemulusan SMA ordo m = 4
m <- 4
data.sma <- SMA(train_ma.ts, n = m)

# Nilai ramalan 1 langkah ke depan
data.ramal <- c(NA, data.sma)

# Peramalan sepanjang horizon data uji (20 periode ke depan)
data.gab <- cbind(
  aktual    = c(penumpang.ts),
  pemulusan = c(data.sma, rep(NA, n_test)),
  ramalan   = c(data.ramal, rep(data.ramal[length(data.ramal)], n_test - 1))
)

Double Moving Average (DMA)

Metode Double Moving Average (DMA) melakukan pemulusan dua kali berturut-turut untuk mengakomodasi adanya kecenderungan pola tren linier.

\[S_{1,t} = \frac{1}{m} \sum_{i=t-m+1}^{t} X_i, \quad S_{2,t} = \frac{1}{m} \sum_{i=t-m+1}^{t} S_{1,i}\]\[A_t = 2S_{1,t} - S_{2,t}, \quad B_t = \frac{2}{m-1}(S_{1,t} - S_{2,t})\]

# Pemulusan tahap 2
dma <- SMA(data.sma, n = m)
At  <- 2 * data.sma - dma
Bt  <- (2 / (m - 1)) * (data.sma - dma)
data.dma    <- At + Bt
data.ramal2 <- c(NA, data.dma)

# Peramalan sepanjang data uji (n_test periode)
f_dma <- numeric(n_test)
for (i in 1:n_test) {
  f_dma[i] <- At[length(At)] + Bt[length(Bt)] * i
}

data.gab2 <- cbind(
  aktual     = c(penumpang.ts), 
  pemulusan1 = c(data.sma, rep(NA, n_test)),
  pemulusan2 = c(dma, rep(NA, n_test)),
  At         = c(At, rep(NA, n_test)), 
  Bt         = c(Bt, rep(NA, n_test)),
  ramalan    = c(data.ramal2, f_dma[-1])
)

SES & DES

##Single Exponential Smoothing (SES)

Metode SES memberikan bobot yang menurun secara eksponensial terhadap pengamatan historis, sangat sesuai untuk data stasioner.

\[\tilde{y}_t = \alpha y_t + (1 - \alpha)\tilde{y}_{t-1}\]

# Model SES dengan parameter coba-coba (alpha = 0.2 dan alpha = 0.7) serta Optimum
ses1   <- HoltWinters(train_ma.ts, alpha = 0.2, beta = FALSE, gamma = FALSE)
ses2   <- HoltWinters(train_ma.ts, alpha = 0.7, beta = FALSE, gamma = FALSE)
sesopt <- HoltWinters(train_ma.ts, alpha = NULL, beta = FALSE, gamma = FALSE)

# Ramalan sepanjang horizon data uji (20 periode)
ramalan1   <- forecast(ses1, h = n_test)
ramalan2   <- forecast(ses2, h = n_test)
ramalanopt <- forecast(sesopt, h = n_test)

cat("Nilai Alpha Optimum SES:", sesopt$alpha, "\n")
## Nilai Alpha Optimum SES: 6.066338e-05
# Plot hasil SES Optimum
plot(ramalanopt, main = "Peramalan SES (Alpha Optimum)")

Pemulusan Data Musiman: Holt-Winters

Karena data jumlah penumpang transportasi harian memiliki pola siklus mingguan (7 hari), data deret waktu dimodelkan menggunakan frekuensi musiman mingguan (\(s = 7\)).

# Mengatur frekuensi musiman mingguan (frequency = 7)
train_season.ts <- ts(training_ma$'Jumlah Penumpang', frequency = 7)
test_season.ts  <- ts(testing_ma$'Jumlah Penumpang', frequency = 7)

Holt-Winters Aditif

Model musiman aditif sesuai jika variasi musiman berfluktuasi secara relatif konstan di sekitar level tren.

# Pemulusan Holt-Winters Aditif
winter_add     <- HoltWinters(train_season.ts, alpha = 0.2, beta = 0.1, gamma = 0.1, seasonal = "additive")
winter_add_opt <- HoltWinters(train_season.ts, seasonal = "additive")

# Peramalan sepanjang data uji
ramalan_add     <- forecast(winter_add, h = n_test)
ramalan_add_opt <- forecast(winter_add_opt, h = n_test)

plot(ramalan_add_opt, main = "Peramalan Holt-Winters Aditif Optimum (Siklus 7 Hari)")

## Holt-Winters Multiplikatif

Model multiplikatif sesuai jika amplitudo musiman bervariasi proporsional terhadap perubahan level data.

# Pemulusan Holt-Winters Multiplikatif
winter_mult     <- HoltWinters(train_season.ts, alpha = 0.2, beta = 0.1, gamma = 0.3, seasonal = "multiplicative")
winter_mult_opt <- HoltWinters(train_season.ts, seasonal = "multiplicative")

# Peramalan sepanjang data uji

ramalan_mult_opt <- forecast(winter_mult_opt, h = n_test)

plot(ramalan_mult_opt, main = "Peramalan Holt-Winters Multiplikatif Optimum (Siklus 7 Hari)")
