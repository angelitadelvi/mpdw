1. Bangkitkan ARMA(2,2) Secara Manual

set.seed(123)

n <- 300

phi1 <- 0.5
phi2 <- 0.2

theta1 <- 0.4
theta2 <- 0.6

e <- rnorm(n, mean = 0, sd = 1)

Y_manual <- numeric(n)

Y_manual[1] <- e[1]
Y_manual[2] <- e[2]

for (t in 3:n) {
  
  Y_manual[t] <-
    phi1 * Y_manual[t - 1] +
    phi2 * Y_manual[t - 2] +
    e[t] +
    theta1 * e[t - 1] +
    theta2 * e[t - 2]
}

head(Y_manual)
## [1] -0.5604756 -0.2301775  0.9031681  0.9614338  1.7540666  2.8784052

Berdasarkan hasil pembangkitan secara manual, diperoleh 300 data dari proses ARMA(2,2) dengan parameter \(\phi_1=0,5\), \(\phi_2=0,2\), \(\theta_1=0,4\), dan \(\theta_2=0,6\). Enam pengamatan pertama yang diperoleh berturut-turut adalah -0,5605; -0,2302; 0,9032; 0,9614; 1,7541; dan 2,8784. Data tersebut menunjukkan adanya fluktuasi nilai dari waktu ke waktu sebagai hasil pengaruh komponen autoregresif, moving average, dan error.

5. Plot PACF

Berdasarkan plot PACF ARMA(2,2), terlihat bahwa terdapat spike yang signifikan pada lag 1 dan lag 2. Dengan demikian, PACF tidak menunjukkan pola cut-off yang benar-benar tegas pada lag 2. Pola tersebut sesuai dengan karakteristik proses ARMA, di mana baik ACF maupun PACF cenderung mengalami tailing off.
